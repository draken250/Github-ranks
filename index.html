    GitHub personal access token

    Unauthenticated requests are limited to 60/hour by GitHub, which is easy to hit with a larger directory. Add a token (no scopes needed — "public_repo" read access is enough) to raise that to 5,000/hour. It is stored only in this browser's localStorage and sent directly to api.github.com, never to any other server.
